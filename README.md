# 海上浮式平台态势与安全联锁原型

一个无构建依赖的静态交互原型，用于演示海上浮式平台在风浪流变化下的连续姿态恢复、压载水转移、系泊响应、起重作业影响预测、高风险步骤冻结和中断恢复校验。

## 启动

直接用浏览器打开 `index.html`，或在当前目录启动本地静态服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/index.html`。

## 已实现能力

- 连续展示横摇、纵摇、艏向、升沉、四个压载舱液位、四点系泊张力、固定甲板载荷和起重状态。
- 支持调整风速、波高、浪向、流速，并根据环境扰动实时更新平台姿态和系泊载荷。
- 支持压载水跨舱转移、泵流量调整、开始吊装、暂停吊装、恢复吊装和吊臂回转。
- 对每个控制步骤执行 20 秒前瞻预测，输出最大姿态、最大系泊张力、吊物与安全区距离以及恢复平衡时间。
- 当动作互相抵消、泵流量超过 12 m³/min、吊物路径进入禁区、姿态超过 ±6° 或张力超过 850 kN 时，仅冻结对应高风险步骤，监测和演算继续运行。
- 冻结时保存时间、风浪、姿态、液位、吊臂、吊钩高度和各系泊点张力快照。
- 恢复时比较现场状态与原方案基线，校验通过后才解除冻结；失败则保留冻结状态并列出可追溯偏差。
- 事件链记录所有操作、预测冻结、运行冻结、暂停、恢复校验、废弃和完成事件，可导出 CSV。

## 交互路径

1. 调整风浪流滑杆，观察姿态和系泊张力变化。
2. 将泵流量调到 16 m³/min 后下达压载转移，可触发“液位转移过快”冻结；点击“采用 10 m³/min”后可重新现场校验。
3. 将目标吊臂方位调到 45° 并改变吊臂方向，可触发设备安全区路径冻结。
4. 开始吊装后点击暂停，再点击恢复，系统会比较暂停基线与当前现场状态。
5. 在事件链卡片点击“导出 CSV”保存审计记录。

## 模型说明

该原型是安全联锁和交互流程演示，不用于工程设计或真实作业许可。物理模型采用简化的二维环境合力、质量重心矩、弹簧阻尼姿态响应和线性系泊张力近似；真实系统应接入平台水动力模型、压载泵 PLC、起重机控制系统、DCS/SIS 和经过校准的传感器数据。

## 文件结构

- `index.html`：页面结构和操作控件。
- `styles.css`：海工暗色仪表盘样式。
- `app.js`：状态模型、预测、风险规则、冻结恢复、审计日志和 Canvas 可视化。
